# Kit de Documentación Comercial y Funcional para Farmacias

Este directorio reúne el paquete de documentación diseñado para presentar **SaaS Stock Deposit Control** a clientes y usuarios del sector farmacéutico (titulares de farmacia, directores técnicos, encargados de depósito y auxiliares).

> **Nota de Alcance:** Toda la documentación de este paquete refleja la operatoria en tiempo real del sistema, excluyendo funcionalidades fuera del alcance comercial actual (como operación offline).
